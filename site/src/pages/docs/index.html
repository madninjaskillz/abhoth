Abhoth documentation

Abhoth is an autonomous coding agent for the models you run. It comes as one abhoth binary that gives you a terminal session, one-shot runs for scripts, a web UI, a desktop app and an OpenAI-compatible router.

InstallWindows installer, Linux AppImage, Cargo or Docker. Quick startConnect a model and finish your first task in five minutes. Configurationconfig.json, permissions, context, sessions and hooks. Local modelsLM Studio, llama.cpp, vLLM, Ollama and inference slots. Web UI--hostui: projects, chat, diffs, terminals and sign-in. Desktop app--desktop: a native window, a tray icon and auto-update. Self-host with DockerRun the web UI on your server, locked down. The routerOne OpenAI-compatible endpoint in front of your engines.

How it fits together

  • The agent runs a loop: it sends your request and the tool list to the model, runs the tools the model calls, feeds the results back, and repeats until the task is done. Risky tools ask first.
  • State lives in ~/.abhoth: config.json, sessions, prompts, projects and the web UI's account database. Set ABHOTH_HOME to put it somewhere else.
  • Project instructions come from ORCA.md, AGENTS.md or CLAUDE.md in your project, so a repo that already has instructions for another agent works as it is.
  • Models are reached over HTTP: any OpenAI-compatible server, native Ollama, or the Anthropic Messages API.

Getting help

Run abhoth --help for the common options, and type /help in a session for the slash commands. /doctor checks your setup. Bugs and ideas go to GitHub Issues.
