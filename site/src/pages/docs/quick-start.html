Quick start

Five minutes from install to your first finished task.

1. Start a model server

Any OpenAI-compatible server works. With LM Studio, load a coding model with tool support (a Qwen coder, for example) and start the local server on port 1234. With llama.cpp:

llama-server -m qwen3-coder-30b-q4_k_m.gguf --jinja -c 65536 --port 1234

More servers, and how to pick a model: Local models.

2. Point Abhoth at it

The first run creates ~/.abhoth/config.json. Set the base URL and your model:

{
  "lmStudio": {
    "baseUrl": "http://localhost:1234/v1",
    "models": ["qwen3-coder-30b"]
  }
}

You can also do this from a session with /config, or in the web UI under Settings, LLM Server. If models is empty, Abhoth uses the model the server has loaded.

3. Give it a task

Open a terminal in your project and start a session:

cd my-project
abhoth

Type what you want, for example "Add a DELETE /todos/:id endpoint, with a test". Abhoth reads the code, makes the change, runs the tests and tells you what it did. Read-only tools run straight away; anything that writes or runs commands asks first. Press Ctrl+C to cancel a turn.

Useful slash commands

CommandWhat it does
/helpLists every command.
/initCreates an ORCA.md with instructions for this project.
/planToggles plan mode: the agent plans first, using read-only tools.
/modelLists or sets the model(s).
/diff, /undoShows uncommitted changes, or undoes the last edit from its checkpoint.
/agentsLists and watches background agents (Ctrl+G).
/reviewRuns a code review in a sub-agent.
/compact, /contextSummarises the conversation, or shows context-window use.
/session, /forkLists, loads and saves sessions, or branches the current one.
/configOpens the settings editor.
/doctorChecks your setup.

Your own commands go in .orca/commands/ as Markdown templates.

Other ways to run it

abhoth -p "fix the failing test"            # one prompt, then exit
abhoth -p "summarise src/" --output json    # machine-readable result
abhoth -c                                   # continue the last session
abhoth --sandbox                            # read-only tools, no shell
abhoth --hostui                             # the web UI
abhoth --desktop                            # the web UI in its own window
