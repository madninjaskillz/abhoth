Configuration

Settings live in ~/.abhoth/config.json. Edit the file, use /config in a session, or open Settings in the web UI. All three write the same file.

Where things live

PathWhat
~/.abhoth/config.jsonAll settings.
~/.abhoth/sessions/Saved conversations (-c, -r <id>, /session).
~/.abhoth/prompts/System prompt templates; default.md is the one in use.
~/.abhoth/abhoth.dbWeb UI accounts, sessions and API keys (SQLite).
ORCA.md, AGENTS.md, CLAUDE.mdInstructions for the agent in this project.
.orca/commands/*.mdYour own slash commands.

Set ABHOTH_HOME to use another state folder (handy for a throwaway setup). OPENORCA_HOME is read as a fallback.

The model server (lmStudio)

The section keeps its historical name, but it works with any OpenAI-compatible server.

KeyDefaultMeaning
baseUrlhttp://localhost:1234/v1The server's OpenAI-compatible endpoint.
apiKeylm-studioSent as a bearer token. Local servers usually accept anything.
models[]Models in priority order: the first is used, and the rest are backups. When empty, the server's loaded model is used.
nativeToolCallingfalseSend tools through the OpenAI function-calling API. When it's off, tools are described in the prompt and parsed from text.
temperature0.7The sampling temperature. sampling and modelSampling give finer control and presets.
timeoutSeconds, streamingTimeoutSeconds120The request timeout, and the idle timeout while streaming.
backupOnRefusal, backupMinResponseLengthoffWhen to move on to the next model.
pairModelProgrammingfalseRuns the models in parallel and lets them vote on the best response.
providerOpenAI-compatibleSet it to "anthropic" to talk to the Anthropic Messages API.

Extra servers go under providers, keyed by name, each with its own type (openai-compat, anthropic or ollama), baseUrl, apiKey or apiKeyEnv, models and contextWindow. See Local models.

Permissions (permissions)

Each tool has a risk level. Read-only tools run without asking by default; tools that write or run commands ask first.

{
  "permissions": {
    "autoApproveReadOnly": true,
    "autoApproveModerate": false,
    "autoApproveAll": false,
    "alwaysApprove": ["edit_file"],
    "disabledTools": [],
    "allowPatterns": ["Bash(git status*)", "Bash(npm test*)"],
    "denyPatterns": ["Bash(rm -rf *)"]
  }
}

Patterns are written Tool(argGlob), and deny wins over allow. On the command line, --allow <tools> pre-approves tools, --allow-dir <dir> keeps file tools inside a folder, and --sandbox allows read-only tools only, with no shell.

Context (context)

  • contextWindowSize: the window size in tokens. With autoDetectContextWindow on (the default), the server's real window is read at startup. A smaller server value wins.
  • autoCompactEnabled and autoCompactThreshold: summarise older turns before the window fills. If the server still reports an overflow, Abhoth compacts and retries once.
  • thinkingAwareCompaction: takes the model's reasoning into account when it compacts.

Thinking (thinking)

level (off, minimal, low, medium, high, unlimited) sends the matching thinking switch and budget to llama.cpp-style servers. reasoningEffort sends reasoning_effort. runawayCapChunks stops a generation that reasons for too long without acting.

Agents (agent)

maxIterations caps the tool rounds in a turn, and the budget is extended while the turn keeps making progress. maxConcurrent limits how many sub-agents run at once. engine picks native, claude or codex, and the --engine flag does the same for one run.

Sessions, hooks and memory

  • session.autoSave and session.maxSessions control saved conversations.
  • hooks.preToolHooks and hooks.postToolHooks run your commands around tool calls, for example a formatter after edit_file.
  • memory turns on the optional auto-memory files that the agent can read in later sessions.

MCP servers (mcpServers)

{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "."],
      "env": {},
      "enabled": true
    }
  }
}

Their tools appear next to the built-in ones and follow the same permission rules.

Environment variables

VariableMeaning

ABHOTH_ADMIN_USER, ABHOTH_ADMIN_PASSWORD_FILECreate the first web UI admin without the setup page.
