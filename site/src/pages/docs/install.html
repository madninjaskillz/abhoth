Install

Releases are on GitHub Releases, packaged with Velopack. The latest is v{{version}}.

Windows

Download Abhoth-win-Setup.exe and run it. It doesn't need admin rights and doesn't ask questions:

  • abhoth.exe and abhoth-desktop.exe go to %LOCALAPPDATA%\Abhoth\current;
  • that folder is added to your user PATH, so abhoth works in a new terminal;
  • an "Abhoth" Start-menu shortcut opens the desktop app, and the installer starts it.

Uninstall from Settings, Apps; the PATH entry is removed too. Your state in ~/.abhoth is never touched by install, update or uninstall.

SmartScreen. The builds aren't code-signed yet, so Windows may warn on the first run. Choose More info, then Run anyway. Each release has a SHA256SUMS file you can check the download against.

To run Abhoth without installing it, download Abhoth-win-Portable.zip. Each release also has a versioned abhoth-<version>-win-x64.zip holding the two bare executables.

Linux

Download Abhoth.AppImage, make it executable and run it. This is the desktop app, and it needs WebKitGTK 4.1.

chmod +x Abhoth.AppImage
./Abhoth.AppImage

For a headless server, use Docker or build the CLI from source.

Updates

The installed desktop app checks for a new release in the background when it starts and then every 6 hours. When it finds one, it downloads it (a small delta package when there is one), and the tray menu shows Update available: restart into <version>. If you don't click it, the update is applied the next time the app starts.

From source (any platform, including macOS)

You need rustup; it installs the toolchain pinned in rust-toolchain.toml. The web client is prebuilt in client/dist, so you don't need Node.

git clone https://github.com/madninjaskillz/abhoth
cd abhoth
cargo build --release                      # target/release/abhoth
cargo build --release --features desktop   # also abhoth-desktop and --desktop

On Linux, the desktop feature needs libwebkit2gtk-4.1-dev, libgtk-3-dev, libdbus-1-dev, libwayland-dev and pkg-config. There's no macOS installer yet, but CI builds and checks the desktop feature on macOS.

Docker

The image runs the web UI with sign-in. Build it from the repo:

docker build -f deploy/docker/Dockerfile -t abhoth-web .

Then follow Self-host with Docker.

Check it works

abhoth --version
abhoth --demo        # a scripted session that needs no model server
