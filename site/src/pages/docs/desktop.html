Desktop app

The web UI in its own window. It uses WebView2 on Windows and WebKitGTK on Linux, so there's no bundled browser.

Start it

  • Installed (Windows): the "Abhoth" Start-menu shortcut runs abhoth-desktop.exe, which has no console window.
  • Linux: run Abhoth.AppImage.
  • From a terminal: abhoth --desktop, in a build with the desktop feature (the release builds have it).

The app starts the web server on loopback and signs you in by itself, without showing a token. The sign-in lasts while the app runs.

Window and tray

  • Closing the window hides it to the tray. The server, your sessions and running agents carry on. Use Show from the tray (or double-click the icon) to bring it back, and Quit to exit.
  • To quit on close instead, turn off desktop.closeToTray in Settings, Desktop. It applies at once.
  • One instance: launching it again brings the existing window forward.
  • The folder picker uses your system's dialog, and links that leave the app open in your normal browser.
  • On Linux without a tray (no StatusNotifier host), closing the window quits.

Updates

The installed app checks GitHub Releases when it starts and every 6 hours. A new version is downloaded in the background, as a delta package when possible, and the tray menu offers Update available: restart into <version>. Otherwise it's applied the next time the app starts. Your ~/.abhoth folder is never touched by updates.

First run

With no model configured, the app still opens. Go to Settings, LLM Server, set the base URL of your model server and its models, and your next prompt uses them. See Local models.
